# COMP205 - Object-Oriented Programming (OOP) Sheets

حلول شيتات وتكليفات مادة البرمجة الشيئية (OOP - COMP205).

## Structure

```text
sheets/
├── sheet1/
│   ├── question1.cpp
│   ├── question2.cpp
│   └── question3.cpp
├── sheet2/
│   ├── question1.cpp
│   └── question2.cpp
└── sheet3/
    ├── question1.cpp
    ├── question2.cpp
    ├── question3.cpp
    └── question4.cpp
```

---

### Sheet 1
- **`question1.cpp`**: دوال تحليل الأرقام (القسمة، القاسم المشترك الأكبر GCD، فحص الأعداد الأولية Prime، عكس خانات الأرقام Reverse، وحساب عدد الخانات).
- **`question2.cpp`**: دوال المصفوفات الديناميكية (قراءة وعرض المصفوفة، البحث والاستبدال، تبديل العناصر Swap، وترتيب المصفوفة Sort).
- **`question3.cpp`**: دوال تحليل المصفوفات (عرض المصفوفة بشكل طولي، عكس عناصر المصفوفة، استخراج العناصر المكررة، وحساب المصفوفة التراكمية Cumulative Sum).

---

### Sheet 2
- **`question1.cpp`**: كلاس `Data` للتعامل مع مصفوفة أرقام، حساب المضروب Factorial، فحص الأعداد الأولية Primes، وجمع/ضرب المضاريب.
- **`question2.cpp`**: كلاس `Point_3D` لتمثيل النقاط ثلاثية الأبعاد وحساب الـ Norm ومقارنة أطول وأقصر مسافة بين النقاط.

---

### Sheet 3
- **`question1.cpp`**: كلاس `Product` (المنتجات، حساب السعر الصافي بعد الضريبة والخصم، والـ Constructors المختلفة مع Copy Constructor).
- **`question2.cpp`**: كلاس `Employee` (الموظفين، مصفوفة المرتبات لـ 4 أشهر، حساب متوسط الراتب الصافي، ومقارنة أعلى وأقل راتب).
- **`question3.cpp`**: كلاس `Complex` (الأعداد المركبة، حساب الـ Magnitude، المقارنة، والـ Negation).
- **`question4.cpp`**: كلاس `patient` (سجلات المرضى، حساب تكلفة الإقامة، خصم كبار السن 60+، وتتبع عدد المرضى عبر Static Member).
